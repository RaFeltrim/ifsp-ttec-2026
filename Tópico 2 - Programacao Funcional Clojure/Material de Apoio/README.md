# Material de Apoio — Tópico 2: Programação Funcional com Clojure

Referências, guias e materiais de estudo sobre a linguagem Clojure e o paradigma funcional na JVM.

---

## 📖 Leituras e Referências Recomendadas

1. **Clojure Official Documentation:** [clojure.org](https://clojure.org/)
   - Visão geral da linguagem, referências de core API e guias de início rápido.
2. **Clojure for the Brave and True:** [braveclojure.com](https://www.braveclojure.com/)
   - Um dos livros mais conceituados e didáticos sobre desenvolvimento prático em Clojure.
3. **Leiningen Build Tool:** [leiningen.org](https://leiningen.org/)
   - Documentação de criação de projetos (`lein new`), execução de testes (`lein test`) e execução (`lein run`).
4. **Cheshire (JSON for Clojure):** [github.com/dakrone/cheshire](https://github.com/dakrone/cheshire)
   - Biblioteca de alta performance para parsing e geração de JSON.
