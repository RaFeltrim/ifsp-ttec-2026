# Avaliação Clojure — TTEC

**Tópicos em Tecnologias Emergentes — IFSP Câmpus São Carlos**

A partir das transações de uma loja (`dados.json`), o programa calcula o total de
vendas concluídas, o total de cancelamentos e o saldo do dia.

## Pré-requisitos

- **Java JDK 8 ou superior**
- **Leiningen**

## Como executar

No terminal, **dentro da pasta do projeto**:

```bash
lein run
```

## Saída esperada

```
Total de vendas concluídas com sucesso: 2
Total de vendas canceladas: 1
Saldo do dia: 125.0
```
